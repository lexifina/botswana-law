# 327. Attempts to commit arson
Any person who-
(a) attempts unlawfully to set fire to any such thing as is mentioned in section 326; or
(b) wilfully and unlawfully sets fire to anything which is so situated that any such thing as is mentioned in section 326 is likely to catch fire from it,
is guilty of an offence and is liable to imprisonment for a term not exceeding 14 years.
