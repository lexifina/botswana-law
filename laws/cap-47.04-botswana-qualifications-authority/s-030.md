# 30. Code of practice and guidelines
(1) The Authority may issue a code of practice and guidelines for any matter falling under its objectives under section 4.
(2) The Authority may, as it considers appropriate, approve of any code of practice or guidelines, or any part of a code of practice or guidelines, drawn up by any other body and issue it as a code of practice for any matter falling under its objectives under section 4.
(3) Any code of practice issued under this section shall be for the purpose of providing guidance with respect to the requirements of the provisions of this Act.
