# 6. Procedure on receipt of nominations
When all nominations have been received, the Chairperson shall announce the names of all candidates who have been duly nominated, and if the number of candidates so nominated does not exceed the number of Specially Elected Members to be elected, the Chairperson shall forthwith declare those candidates to have been elected as Specially Elected Members. If the number of candidates so nominated exceeds the number of Specially Elected Members to be elected, a poll shall be taken as provided in the following rules and the Secretary shall write the names of the candidates and the number of Specially Elected Members to be elected on a blackboard placed in full view of all the Members.
