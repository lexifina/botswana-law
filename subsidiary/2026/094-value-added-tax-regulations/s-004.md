# 4. Value Added Tax registration certificate
A Value Added Tax registration certificate issued to a registered person under section 15(6) of the Act shall include the following-
(a) the name and address of the registered person;
(b) the Tax Identification Number of the registered person and Value Added Tax registration number of the person;
(c) information regarding the taxpayer category;
(d) the date that the certificate was issued; and
(e) the date from which registration takes effect.
